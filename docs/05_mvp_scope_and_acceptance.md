# 05. MVP範囲・受入条件・KPI

## 1. MVPに入れる

- 外構案件作成
- 工事条件チェックリスト
- 条件書PDF・共有文生成
- PDF、画像、カメラ取り込み
- 最大3社比較
- 日本語OCR
- 総額、税、値引き抽出
- 明細行抽出
- 元画像を見ながら修正
- 外構用共通カテゴリ
- 含む・別途・不明の比較
- 一式・別途・概算等の検出
- 業者への質問文
- 修正版見積書
- 改訂差分
- 案件単位リワード広告
- 端末内保存
- 案件完全削除

## 2. MVPに入れない

- 業者紹介・送客
- 業者ランキング
- 口コミ
- 市場相場比較
- 悪質業者判定
- 法的判断
- 全業種対応
- クラウド同期
- 家族アカウント
- AIによる業者推薦
- 自動価格交渉
- iOS同時公開

## 3. 機能受入条件

### 入力

- PDF/JPEG/PNGを登録できる
- 複数ページの順番を修正できる
- ページを除外・再撮影できる
- 解析失敗時に手動補正へ移れる

### 金額

- 税込総額をユーザーが確認できる
- 数量×単価の不一致を検出できる
- 小計と総額の不一致を検出できる
- OCR結果を根拠画像から確認できる
- 不確実な金額を自動確定しない

### 比較

- 会社ごとに総額を表示できる
- 同一カテゴリを横並び表示できる
- 必須項目の含有状態を表示できる
- 別途・不明を区別できる
- 条件差が大きい場合に比較不能と表示できる
- 総合ランキングを自動生成しない

### 質問

- 不明事項から質問文を生成できる
- 業者別にコピーできる
- 回答内容を保存できる
- 回答後に不明状態を更新できる

### 改訂

- 初版を上書きせず改訂版を追加できる
- 金額、数量、仕様、含有状態の差分を表示できる

### 広告

- ユーザー操作でのみリワード広告を開始する
- 報酬完了後に案件を永久解放する
- 広告在庫なしでも基本比較を継続できる
- 入力済みデータの閲覧・修正・削除を広告で妨げない

## 4. 非機能条件

- 文書を端末内へ保存
- 広告SDKへ文書内容を渡さない
- 削除操作で関連ファイルも削除
- アプリ再起動後も解放状態を保持
- 解析途中で終了しても再開可能
- 根拠のない断定を表示しない

## 5. 事前検証

個人情報を除去した実見積書20～30件を目標に確認する。

- 総額位置
- 明細表形式
- 改ページ
- 一式の使用
- 数量・単価欠落率
- 除外条件
- 商品型番
- 表記揺れ
- 手書き訂正
- OCR修正件数

件数は開発目標であり、統計的妥当性を保証する数字ではない。

## 6. KPI

### 最重要

- 見積書取り込み完了率
- 比較画面到達率
- 比較完了率
- 1社当たり修正項目数
- 比較完了までの時間

### 価値確認

- 質問文コピー率
- 業者回答記録率
- 修正版追加率
- 不明項目の解消率

### 収益確認

- リワード広告選択率
- 広告完了率
- 広告後の詳細機能利用率
- 買い切り転換率

## 7. 仮説として置く目標

以下は未検証のため、リリース判断では実測する。

- 通常の確認件数: 1社3～8件
- 認識状態が悪い文書: 1社10～20件
- 最初の比較完了: 10分以内
- 基本比較到達前の広告表示: 0回
