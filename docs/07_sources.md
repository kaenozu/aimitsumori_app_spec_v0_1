# 07. 参考資料

2026年7月16日時点で確認した公式資料。

## ML Kit Document Scanner

- Android向け文書スキャナー
- 複数ページ、スキャンUI、JPEG/PDF出力
- モデル、スキャンロジック、UIフローがGoogle Play開発者サービスから動的に提供される

https://developers.google.com/ml-kit/vision/doc-scanner/android

## ML Kit Text Recognition v2

- 日本語を含む文字体系へ対応
- テキストブロック、行、要素、位置情報などを取得可能

https://developers.google.com/ml-kit/vision/text-recognition/v2
https://developers.google.com/ml-kit/vision/text-recognition/v2/android
https://developers.google.com/ml-kit/vision/text-recognition/v2/languages

## AdMob Rewarded Ads

- ユーザーの明示操作後に表示
- 報酬獲得コールバックを受けて機能解放する

https://developers.google.com/admob/android/rewarded
