# 02. ユーザーフローと画面仕様

## 1. ホーム

表示:

- 新しい案件
- 進行中案件
- 比較待ち
- 業者回答待ち
- 完了案件

主要操作:

- `条件書を作る`
- `見積書を比較する`

## 2. 新規案件

入力:

- 案件名
- 工事カテゴリ
- 比較予定社数
- 希望時期
- メモ

住所や電話番号は必須にしない。

## 3. 工事条件チェックリスト

### 駐車場

- 台数
- 仕上げ
- 面積
- コンクリート厚
- 配筋
- 目地
- 勾配
- 排水
- 既存構造物撤去

### フェンス

- 設置範囲
- 高さ
- 目隠し率
- 商品指定
- 基礎ブロック

### カーポート

- 台数
- メーカー・型番
- 耐雪
- 耐風
- 照明・電源
- 土間工事との取り合い

### 共通

- 解体撤去
- 残土処分
- 養生
- 重機回送
- 交通誘導
- 申請
- 諸経費
- 税
- 保証
- 追加料金条件

各項目を次の状態で管理する。

- 必須
- 任意
- 不要
- 未設定

## 4. 条件書プレビュー

出力内容:

- 工事条件
- 必須仕様
- 見積もりへ記載してほしい内容
- 別途費用の明示依頼
- 商品メーカー・型番の明示依頼
- 数量・単位・単価の明示依頼
- 保証と支払条件の明示依頼

操作:

- PDF保存
- 共有
- 文章コピー
- 条件編集

## 5. 見積書追加

入力元:

- PDF
- ギャラリー
- カメラ
- 共有受信

入力項目:

- 業者名（自動候補、修正可）
- 初版・改訂版
- ページ順
- 不要ページ除外

制限案:

- 1案件3社
- 1社15ページ
- PDF/JPEG/PNG
- 日本語印刷文字を正式対応
- 手書きは参考扱い

## 6. 解析中

段階表示:

1. ページを準備
2. 文字を読み取り
3. 金額と明細を抽出
4. 共通項目へ整理
5. 確認事項を作成

失敗時:

- 該当ページを再撮影
- 画像を回転
- 手動で総額を入力
- 読み取り対象から除外

## 7. 確認ボックス

全明細を確認させず、重要かつ不確実な項目だけ表示する。

質問例:

- 税込総額は1,283,700円で正しいですか
- 残土処分は総額に含まれていますか
- この「一式」は土工事として扱いますか
- 商品型番が読み取れませんでした
- 数量×単価と金額が一致しません
- 小計と総額が一致しません

回答:

- 正しい
- 修正
- 不明
- 業者へ確認
- 対象外

必ず元文書の該当部分を併記する。

## 8. 比較サマリー

最初に3行程度の要約を表示する。

例:

- 最安はA社。ただし残土処分と電気工事が別途
- B社は12万円高いが必須項目がすべて含まれる
- C社は数量・商品型番が不明で現時点では正確に比較できない

表示カード:

- 税込総額
- 必須項目の充足
- 別途項目
- 不明項目
- 一式項目
- 保証
- 支払条件
- 比較可能性

## 9. 項目別比較

行:

- 共通カテゴリ
- 仕様
- 数量
- 単価
- 金額
- 含有状態
- 根拠ページ

列:

- A社
- B社
- C社

フィルター:

- 金額差が大きい
- 必須項目
- 別途
- 不明
- 一式
- 商品型番なし
- 数量なし

## 10. 質問文

機能:

- 全質問を生成
- 業者別に分割
- LINE向け短文化
- メール向け整形
- コピー
- 回答済み
- 回答内容記録
- 修正版追加

## 11. 改訂履歴

表示:

- 初版総額
- 最新版総額
- 増減額
- 追加項目
- 削除項目
- 数量変更
- 仕様変更
- 未解決事項

旧版は上書きしない。
