# Android実機受入テスト

## 目的

カメラ、端末内OCR、SQLite永続化、共有、広告、アプリ内課金を、実際のAndroid端末と本番相当設定で確認するための受入テストです。自動テストとエミュレータE2Eでは検出しにくい、権限、カメラ品質、ストア連携、ライフサイクル、端末差異を対象にします。

## 完了条件

- P0 / P1 の全ケースが成功している
- P2 の未実施または失敗には理由とフォローアップIssueがある
- 重大なクラッシュ、データ消失、二重課金、権利誤付与がない
- 実行端末、OS、アプリ版、ビルドSHA、ストアトラック、証跡が記録されている
- 本番署名、本番パッケージ名、本番課金商品ID、本番AdMob IDを確認している

## テスト用データ

- 1ページの鮮明な日本語見積書
- 3ページ以上の日本語見積書
- 傾き、影、折れ、低照度を含む見積書
- `数量 × 単価 != 金額` の不整合を含む見積書
- 税込・税抜・値引き・別途費用・オプションを含む見積書
- 2社以上で同一カテゴリの表記が異なる見積書
- 購入検証APIの成功、429、5xx、タイムアウトを再現できる環境

## P0: データ損失・課金・クラッシュ

### A-01 初回起動と権限拒否

- [ ] 初回起動でクラッシュしない
- [ ] カメラ権限を拒否しても案件作成・手入力・PDF読込を利用できる
- [ ] カメラ機能を開いたとき、権限が必要な理由と再試行方法が表示される
- [ ] 「今後表示しない」後も設定画面への導線がある

**証跡:** スクリーンショット、端末ログ

### A-02 単一ページ撮影

- [ ] カメラプレビューが正常に表示される
- [ ] 縦向き・横向きの撮影で画像が欠けない
- [ ] 撮影後にプレビュー、再撮影、確定ができる
- [ ] 確定後、OCR確認画面へ遷移する
- [ ] 戻る操作で一時画像が不正に残らない

**証跡:** 撮影前後のスクリーンショット、OCR結果

### A-03 連続撮影

- [ ] 3ページ以上を順番どおり追加できる
- [ ] ページ削除、再撮影、並べ替えが結果へ反映される
- [ ] 画面回転、バックグラウンド復帰後も撮影中データが破損しない
- [ ] OCR完了または画面終了後に一時画像が削除される

**証跡:** ページ一覧、端末ストレージ確認

### A-04 日本語OCRと数値抽出

- [ ] 会社名、項目名、金額、数量、単位、仕様が概ね読み取れる
- [ ] `1,234,567円`、全角数字、税込・税抜、マイナス値を確認できる
- [ ] 誤認識した文字・金額・数量を手動修正できる
- [ ] 修正内容を保存し、再表示しても維持される
- [ ] 低信頼度または重大な未確認項目が明示される

**証跡:** 原本、OCR初期結果、修正後結果

### A-05 不整合検出

- [ ] 数量×単価と金額が不一致の場合に警告される
- [ ] 合計金額と明細合計が不一致の場合に警告される
- [ ] 不正な金額・数量は保存されず、具体的な入力エラーが表示される
- [ ] 警告を確認したうえで保存できるケースと、保存禁止ケースが仕様どおりである

**証跡:** 警告表示、保存結果

### A-06 SQLite永続化と復旧

- [ ] 案件、要望、2社以上の見積、比較結果を保存できる
- [ ] アプリをタスクキルして再起動してもデータが残る
- [ ] 端末再起動後もデータが残る
- [ ] 既存データを保持したままアプリを上書き更新できる
- [ ] v1相当データから現行DBへ更新した端末で、案件・見積・比較を開ける

**証跡:** 更新前後の画面、アプリ版、DB migrationログ

### A-07 比較と改訂履歴

- [ ] 2社以上の見積を18カテゴリで比較できる
- [ ] 総合点や順位ではなく、価格差、範囲差、別途費用、オプション、不明点が表示される
- [ ] 同一業者の改訂版を追加し、版間差分を確認できる
- [ ] 比較対象の版を切り替えても元データが変更されない
- [ ] 比較結果更新後、アプリ再起動しても結果が一貫している

**証跡:** 比較画面、改訂差分画面

### A-08 全データ削除

- [ ] 「全データを削除」の確認ダイアログが表示される
- [ ] キャンセル時にデータが残る
- [ ] 実行時に案件、見積、比較、改訂、要望、OCR確認状態、一時画像が削除される
- [ ] 削除後にアプリを再起動してもデータが復元されない
- [ ] 広告削除権利など、購入に由来する復元可能な権利の扱いが仕様どおりである

**証跡:** 削除前後の画面、再起動後画面

### A-09 広告削除購入

- [ ] Google Playのライセンステスターで本番と同一の商品IDを取得できる
- [ ] 購入前は広告が表示される
- [ ] 購入成功後、購入検証APIの成功確認後に広告が非表示になる
- [ ] 二重タップや画面再生成で購入処理が重複しない
- [ ] 購入完了通知の再配信でも権利が二重付与・破損しない
- [ ] アプリ再起動後も広告削除権利が維持される

**証跡:** Play購入画面、検証APIログ、購入前後画面

### A-10 購入復元

- [ ] アプリ再インストール後に購入復元できる
- [ ] 同一Google Playアカウントで広告削除権利が復元される
- [ ] 未購入アカウントでは権利が付与されない
- [ ] 復元処理を連続実行してもクラッシュや二重完了がない

**証跡:** 再インストール前後、復元結果、APIログ

### A-11 購入検証API障害

- [ ] タイムアウト、429、5xxで再試行可能なエラーとして扱われる
- [ ] 直近に検証済みの広告削除権利を一時障害だけで即時剥奪しない
- [ ] 未検証の新規購入を通信失敗だけで恒久的に成功扱いしない
- [ ] 再試行後の成功で購入処理が完了する
- [ ] 商品ID不一致または`valid: false`で権利を付与しない

**証跡:** APIレスポンス、端末画面、再試行ログ

## P1: 主要UXと端末連携

### B-01 PDF・写真ライブラリ読込

- [ ] 1ページPDFと複数ページPDFを読み込める
- [ ] 写真ライブラリから1枚・複数枚を選択できる
- [ ] 読込キャンセルで空の見積や壊れた下書きが作られない
- [ ] 大きなPDF・画像でもOOMや無応答にならない
- [ ] 対応外ファイルには理解可能なエラーが表示される

### B-02 共有・エクスポート

- [ ] PDF、PNG、CSV、テキストを生成できる
- [ ] Android共有シートが開く
- [ ] 共有キャンセル後もアプリへ正常に戻れる
- [ ] 出力内容に選択した案件・比較結果だけが含まれる
- [ ] 個人情報や内部デバッグ値が意図せず出力されない

### B-03 広告表示

- [ ] 本番AdMobアプリID・広告ユニットIDで起動できる
- [ ] バナー表示失敗時も主要操作を妨げない
- [ ] リワード広告の完了・中断・読込失敗を区別できる
- [ ] 広告削除購入済みではバナーと購入導線が仕様どおりになる

### B-04 ライフサイクルと割込み

- [ ] 撮影中の電話・通知・画面OFFから復帰できる
- [ ] OCR中にバックグラウンドへ移動してもクラッシュしない
- [ ] 共有先から戻った後も画面状態が破損しない
- [ ] Androidの戻るジェスチャーで意図しないデータ消失がない

### B-05 ネットワーク切替

- [ ] オフラインでも案件、見積、OCR、比較を利用できる
- [ ] Wi-Fiからモバイル回線へ切り替えても購入検証を再試行できる
- [ ] 機内モード解除後に復元処理を再実行できる

## P2: 端末差異・アクセシビリティ

### C-01 画面サイズと表示倍率

- [ ] 小型端末で主要ボタンが画面外へ隠れない
- [ ] 大きいフォント設定でテキストが欠けず、操作不能にならない
- [ ] ダークモードで文字、警告、選択状態のコントラストを確認する

### C-02 アクセシビリティ

- [ ] TalkBackで主要ボタン、入力欄、警告を識別できる
- [ ] フォーカス順が操作順と一致する
- [ ] 色だけに依存せず、警告・選択・成功状態を理解できる

### C-03 性能

- [ ] 10件以上の案件、各案件3社以上の見積でも一覧と比較が実用速度で開く
- [ ] 10ページ相当の画像OCRでクラッシュしない
- [ ] 長時間操作後もカメラ、一時画像、メモリが増え続けない
