# 相見積もり支援アプリ 仕様パッケージ v0.1

複数社の見積条件をそろえ、見積書の差・抜け・不明点を可視化し、
契約前に業者へ確認できる状態を作る個人向けアプリの仕様案です。

## 想定MVP

- 対象業種: 外構・エクステリア工事
- 対象OS: Android
- 保存方式: 端末内保存
- 入力: PDF、画像、カメラ、共有、手動補正
- 収益化: 案件単位のリワード広告 + 広告不要の買い切り
- 非対応: 業者ランキング、相場断定、法的判断、クラウド同期

## 中核方針

1. 完全手入力を主経路にしない
2. 「撮影・選択 → 自動抽出 → 怪しい箇所だけ確認」にする
3. 最安業者を断定せず、条件差と未確認事項を示す
4. 不明な情報は不明のまま扱う
5. 広告を見ないと入力済みデータへアクセスできない設計にしない
